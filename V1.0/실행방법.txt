=== AutoCheck 사용 안내 (EXE) ===

AutoCheck 는 네트워크 장비 정기점검 도구입니다. 장비에 SSH 로 점검 명령을 보내
원본 로그를 남기고, 로그 분석·마스킹·정기점검 보고서(Excel·PDF)·SecureCRT 실시간
감시를 한 화면에서 합니다.


--- 1. 실행 ---

이 폴더(AutoCheck)를 통째로 원하는 곳에 두고 AutoCheck.exe 를 더블클릭합니다.
  - 폴더 안의 _internal 폴더는 지우거나 옮기지 마세요(실행에 필요한 파일입니다).
  - Python 은 따로 설치하지 않아도 됩니다.
  - 창이 뜨지 않으면 Microsoft Edge WebView2 Runtime 이 있는지 확인하세요
    (Windows 10/11 에는 보통 들어 있습니다).


--- 2. 처음 할 일 (왼쪽 메뉴) ---

  1) 워크스페이스      고객사를 추가하고 정기점검 회차(프로파일)를 만듭니다.
  2) 장비 목록        관리 IP·계정을 넣고 점검할 장비를 켭니다.
  3) 명령어 카탈로그  점검 때 장비에 보낼 명령을 메모장처럼 적습니다(명령 다음 줄에 !, 읽기 전용 명령만).
  4) 세션 터미널      '세션 점검'으로 원본 로그를 모읍니다.
  5) 보고서           정기점검 보고서(Excel·PDF)를 만듭니다.

각 화면 위쪽의 설명과 버튼의 도움말을 참고하세요.


--- 3. 데이터가 저장되는 곳 ---

점검 로그·보고서·설정은 "문서\AutoCheck"(Documents\AutoCheck) 폴더에 쌓입니다.
  - 새 버전으로 바꿀 때는 이 EXE 폴더만 바꾸면 됩니다. 데이터는 그대로 남고,
    새 버전을 처음 열 때 필요한 업그레이드를 합니다.
  - 설정·장비 목록·명령 카탈로그는 하루 한 번 Documents\AutoCheck\backups 에
    자동으로 백업됩니다(최근 10개). 이 PC 안에 남으므로 중요한 데이터는 따로 복사하세요.
  - 데이터를 이 EXE 폴더 안에 두려면(포터블) 이 폴더에 autocheck_data 폴더를 만드세요.
  - 장비 비밀번호·API 키는 이 PC 의 이 Windows 사용자만 풀 수 있게 봉인됩니다.
    데이터 폴더를 다른 PC 로 옮기면 비밀번호·API 키를 다시 입력해야 합니다.


--- 4. 무인 정기점검 ---

워크스페이스의 '무인 정기점검' 카드에서 일정을 저장하면 Windows 작업 스케줄러에
등록되어, 그 시각에 창 없이 점검 → 분석 → 보고서를 만듭니다.
  - PC 가 켜져 있고 일정을 저장한 Windows 사용자가 로그인해 있어야 돕니다
    (화면 잠금은 괜찮습니다).
  - 새 버전으로 바꾼 뒤에는 앱을 한 번 열어야 무인 점검이 돕니다.
  - 이 EXE 폴더를 다른 곳으로 옮기면 일정을 다시 저장하세요(작업이 EXE 위치를 기억합니다).


--- 5. 문제가 생기면 ---

  - '전체 로그' 메뉴의 '진단 번들'로 zip 을 만들어 담당자에게 보내 주세요.
    비밀번호·키는 늘 지우고, 장비·고객사 이름과 IP 도 기본으로 가립니다.
  - 앱 로그는 Documents\AutoCheck\logs 에 있습니다.
